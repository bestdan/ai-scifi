# Egan lens: stress test of the bible (run-06)

Blind spots: I read for rules and arithmetic. I can over-weight a derivation
against a scene, and I say little about whether Mariam or Lamara feel like
people. Let Le Guin and the First Reader overrule me on that. Each fix below
can be one or two plain sentences on the page.

1. **[must-fix] The instance is a function of a public record, so anyone can
   run it early.** The boot is "the record and nothing else". The record is
   public. Anyone with the record and the weights can therefore boot a shadow
   instance on Davit's draft schedule and read the determination in advance.
   Davit would never need to ask Akinyi for a line, and the Part 5 suspense
   would be gone. It also makes "erased at night" empty: the same morning can
   be re-run. Fix: say on the page why this can't happen (the weights run only
   in commons facilities; output varies run to run; the charter makes a
   shadow run an offence). Then say whether the appeal panel may order a re-run.

2. **[must-fix] Memos are record, and that is a lawful memory channel.** The
   bible says the instance "can't hold a lesson". But instance N reads N−1's
   memo, and the Ulaanbaatar failure could have been fixed by a memo line:
   "Do not repeat an order whose fault report may be in the lag." Nine years
   of Akinyi's lines would be redundant. Also, the instance reads everything,
   including 3,300 errata that expand a phrase into a sentence, and it is
   defined as the reader who notices footnotes. Why does it never flag them?
   Fix: a charter rule that memos describe and never instruct, and that
   predecessors are testimony, not authority. And say that errata enter the
   record as clean replacement text with no visible diff. Settle what the
   line carries. The bible says both "what that day's instance learned" and
   "the intake that won't be gazetted for three days". The second is what
   she can actually see.

3. **[must-fix] Arithmetic errors.**
   - The final memo line reads "Ketevan Kiknadze, nurse, 2041–2090,
     deceased". The numbers table has her born 2019 and dead December 2096.
   - "About 3,300" lines is more than the 3,287 nights between January 2089
     and January 2098, before any nights off. Say about 3,200 and give the
     nights she missed. Each missed night is a story: what did the next three
     mornings not know?
   - The filing cutoff is 25 February in the bible, but its own rule
     ("filed Monday, read Thursday") puts a 26 February filing in the 1 March
     instance. Decide which, and have Davit's line say it.
   - The honest schedule gazettes on 28 February, so instance 13,515 already
     reads Ketevan's name. Her name appearing first in 13,516 is wrong. Put
     the line in 13,515's memo, or have a later amendment add her.

4. **[must-fix] Carriage scope breaks the ending.** If cross-border carriage
   is commons, a nurse crossing at Sadakhlo for a shift swap is carried, and
   persons have a registry. Then the governor licenses the nurses along with
   the medicines, and the 400 prosecutions and the amnesty bill go away.
   Fix: define carriage as goods and vehicles, with persons crossing as
   national immigration business. State it where Armen's joke lands. If the
   edge case is wanted, make it a plot turn: Tamar argues the nurses are
   carried too, and the determination declines.

5. **[should] The lag against operations.** Orbit, air and grid can't be run
   from three-day-old data (a 7 km/s object moves). Fix: one line saying
   sensor telemetry is a live operational record, and only attested human
   filings are lagged. Then explain why the Ulaanbaatar fault was a human
   filing. The memo's "eleven fewer than yesterday" should read "than the
   record last showed".

6. **[should] The refusal standard.** "Can no longer run" is read in the
   present tense, and the honest schedule shows 640 nurses with median age 68
   and a 38% vacancy rate. A literal reader would project failure within a
   decade. If it doesn't, the standard seems to be unsatisfiable while the
   doors are open. Fix: the determination should say it judges present
   capacity, and Tamar or Davit should cite Armenia 2087 in one line, naming
   what record satisfied the test there.
